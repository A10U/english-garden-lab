# English Garden Lab — สวนภาษา AI

เครื่องมือฝึกภาษาอังกฤษสำหรับผู้เริ่มต้น มีคำแปลและตัวช่วยภาษาไทย

**[เปิดเดโมออนไลน์](https://a10u.github.io/english-garden-lab/)** · [GitHub repository](https://github.com/A10U/english-garden-lab)

- **[Learning App](app/index.html)** — 3 บทเรียน สวนคำศัพท์ และความก้าวหน้าที่บันทึกในเบราว์เซอร์
- **[Speech Training](speech-training/listen.html)** — 24 ประโยค ตัวอย่างเสียง AI, IPA, ฟังรายคำ และวิเคราะห์เสียงที่บันทึกในเบราว์เซอร์
- **[Speak Studio](app/speak.html)** — พื้นที่อัด/ฟังในเครื่อง บทสนทนาตัวอย่าง และสนทนา/ถอดเสียงผ่าน Cloud เมื่อเชื่อมบริการบน Sites

## Speak แบบผสมและเซิร์ฟเวอร์

เว็บ Sites ใช้ Vinext/Cloudflare Worker เพื่อให้หน้าเดิมกับ `/api/speak` อยู่ในโดเมนเดียวกัน บทเรียนและหน้า Speech เดิมยังเป็น HTML/JS ปกติ ส่วน GitHub Pages ใช้เฉพาะไฟล์ static และไม่มี Cloud API จึงแสดงตัวอย่างและการฝึกในเครื่องได้

```sh
npm ci
npm run dev
```

เปิด `http://127.0.0.1:5173/app/speak.html` การ build สำหรับ Sites ใช้ `npm run build` ซึ่งสร้างไฟล์เว็บเดิมใน `public/` แล้วรวม server กับ assets ใน `dist/` ส่วนการเผยแพร่ GitHub Pages ให้รัน `python3 speech-training/build_demo.py --output .build/github-pages-speak` แล้วใช้เฉพาะไฟล์ static ในโฟลเดอร์นั้น

ผู้ใช้แต่ละคนใส่ OpenAI API key ของตัวเองในช่องรหัสผ่านหน้า Speak แล้วกด “ใช้ key นี้” ได้ key จะอยู่เฉพาะหน่วยความจำของแท็บ ไม่เก็บใน localStorage, sessionStorage, cookie, URL หรือฐานข้อมูลของแอป ช่องกรอกจะถูกล้างหลังตั้งค่า ใช้ได้ผ่าน HTTPS หรือ localhost เท่านั้น กด “ล้าง key” หรือออกจากหน้าเพื่อล้าง key และยกเลิกคำขอที่กำลังทำอยู่ การตรวจบริการทุกครั้งไม่ส่ง key และไม่เรียก OpenAI โดยรอ `/api/speak/health` ยืนยัน `supportsPersonalKey: true` ก่อนเปิดใช้ส่วนตัว จึงแสดงว่า “พร้อมลองใช้งานด้วย key ของคุณ” และยังไม่ได้ตรวจสอบสิทธิ์หรือโควตา จะทราบผลจริงเมื่อผู้ใช้เลือกส่งข้อความหรือถอดเสียง ซึ่งอาจมีค่าใช้บริการในบัญชีของผู้ใช้ บน GitHub Pages หรือบริการที่ไม่รองรับจะล้าง key โดยไม่ส่งออกจากแท็บ และแสดงลิงก์ไปหน้า Speak ที่รองรับ Cloud

key ส่วนตัวส่งใน header เฉพาะ `/api/speak` บนโดเมนเดียวกัน เซิร์ฟเวอร์ใช้เฉพาะคำขอนั้นเพื่อเรียก OpenAI และไม่บันทึกหรือส่ง key กลับในผลลัพธ์ ถ้าไม่มี key ส่วนตัวจึงใช้ secret `OPENAI_API_KEY` ของเซิร์ฟเวอร์ได้ โดยหน้าเว็บระบุแหล่ง key ให้ชัดเจน หากส่ง key ส่วนตัวที่ไม่ถูกต้องจะไม่มีการสลับไปใช้ key เซิร์ฟเวอร์ ค่าเลือกโมเดลคือ `OPENAI_SPEAK_MODEL` (เริ่มต้น `gpt-5.6-terra`) และ `OPENAI_TRANSCRIBE_MODEL` (เริ่มต้น `gpt-transcribe`) ดูชื่อค่าใน `.env.example` อย่าใส่ key ใน source หรือ repository; ตั้ง key เซิร์ฟเวอร์เป็น secret ผ่าน Sites หากต้องการใช้ทางเลือกนี้

เสียงถูกส่งเฉพาะเมื่อกดถอดเสียง ส่วนข้อความและผลหน่วยเสียงที่เลือกถูกส่งเฉพาะเมื่อกดส่งให้มะลิ ผลเสียงต้องตรงกับคลิปและข้อความเดียวกัน และไม่มีการให้ LLM สร้างคะแนนออกเสียงเอง Cloud API ตรวจผู้ใช้ที่ลงชื่อเข้าใช้และ Origin ก่อนเรียกบริการ เก็บคำขอไว้ในหน่วยความจำระหว่างประมวลผล ไม่บันทึกเสียงบนเซิร์ฟเวอร์ของแอป เสียงอ่านคำตอบใช้เสียงอังกฤษที่ติดตั้งในอุปกรณ์

เปิด `index.html` เพื่อเลือก App หรือ Speech Training

แตะคำเพื่อดูตัวสะกดกับเสียง เช่น **leaf → l / ea / f → /l/ /iː/ /f/** โดย `ea` ใช้สองตัวอักษรแทนเสียงเดียว ต่างจากการอ่านชื่ออักษร **L–E–A–F** เพื่อสะกดคำ มีตัวช่วยกลุ่มอักษรและอักษรไม่ออกเสียงสำหรับคำที่เตรียมไว้ พร้อมฝึกทั้งประโยค คำ หรือหน่วยเสียงที่เลือก การฝึกหน่วยเสียงเดี่ยวเป็นโหมดทดลอง ผลจากโมเดลเป็นค่าประมาณสำหรับช่วยฟังและฝึก ไม่ใช่คะแนนออกเสียงที่สอบเทียบแล้ว

เสียงตัวอย่างรายคำใช้ไฟล์ที่สังเคราะห์เป็น **คำเต็มแยกคำ** เมื่อเลือกหน่วยเสียง แอปให้ฟังคำเต็มพร้อมบอกตำแหน่งเสียงและวิธีออกเสียง แทนการตัดเสียงสั้นจากประโยค เสียงที่คุณบันทึกเล่นเป็นไฟล์เต็มด้วย

ส่วนเปรียบเทียบสระให้ฟังคำคู่ **A/B** จากเสียงผู้พูดเดียวกัน เลือกฟังช้าแล้วสังเกตตำแหน่งลิ้นและริมฝีปาก แต่ละด้านเป็นคำเต็มที่สังเคราะห์แยกไว้ พร้อมคำอธิบายเสียงสระที่ต่างกัน

มีเสียงสระเดี่ยวจากผู้สาธิตมนุษย์สำหรับเทียบคุณภาพสระตาม IPA พร้อม [เครดิตเสียงต้นฉบับ](app/assets/vowels/ATTRIBUTION.md) ตัวอย่างเหล่านี้ไม่แสดงความยาวสระภาษาอังกฤษในคำ ดูวิดีโอสอนเพิ่มเติมได้เมื่อกดเปิด โดยไม่เล่นอัตโนมัติ

หลังวิเคราะห์ ช่องรายเสียงบอกสิ่งที่โมเดลจับคู่ได้ และแยกคำถอดเบื้องต้นออกจากผลประเมิน หากโมเดลยังไม่มั่นคงจะคง “—” พร้อมบอกข้อจำกัดของโมเดล โดยไม่จัดอันดับว่าผู้เรียนพูดผิดตรงไหน มีแบบฝึกตามคำอ้างอิง ปุ่มฟังคำเต็ม/เสียงของตัวเอง และการสังเกตด้วยตนเองที่ล้างเมื่อเปลี่ยนคลิป ตัวเลขจับคู่รายเสียงอยู่ในรายละเอียดดิบ ไม่ใช่คะแนนการออกเสียงที่สอบเทียบแล้ว

การเทรนบน Cloud GPU แล้วนำไฟล์โมเดลกลับมาใช้ในเครื่อง ใช้โมเดลเปิดและบัญชี GPU แยกจาก OpenAI API ดู [ขั้นตอน Hugging Face Jobs](speech-training/CLOUD_TRAINING.md) งานนี้ไม่อ่าน `.env.speech-cloud` และไม่ส่งเสียงส่วนตัวของผู้เรียนไปเทรน

ตัวช่วยพื้นฐานการเกิดเสียงอธิบายตำแหน่งและวิธีใช้ลิ้น ริมฝีปาก ทางลม และการสั่นของเส้นเสียง พร้อมขั้นตอนลองทำทีละส่วนและแผนภาพช่วยเรียนโดยประมาณ เป็นพื้นฐานสัทศาสตร์ ไม่ใช่ประวัติที่มาของคำ ระบบวิเคราะห์เสียงที่บันทึก ไม่ได้วัดตำแหน่งปากหรือลิ้นจากภาพ

ภาพประกอบการออกเสียงมีผู้สร้าง แหล่งต้นฉบับ และสิทธิ์กำกับรายภาพ ดู [เครดิตภาพและใบอนุญาต](app/assets/articulation/ATTRIBUTION.md) ซึ่งแยกจากสิทธิ์ของเสียงตัวอย่างและโค้ด

## เปิดเดโมในเครื่อง

ต้องมี Python 3 และใช้ HTTPS หรือ localhost เพื่อบันทึกเสียง:

```sh
python3 speech-training/build_demo.py
python3 -m http.server 8080 --directory dist
```

เปิด http://localhost:8080 แล้วอนุญาตไมโครโฟนเมื่อต้องการบันทึกเสียง กดดูผลเพื่อวิเคราะห์เสียงของคุณในเบราว์เซอร์ ครั้งแรกดาวน์โหลดโมเดลประมาณ **318 MB** จาก Hugging Face และชุดประมวลผลประมาณ **12 MB** จากเว็บนี้ เสียงที่บันทึกไม่ถูกส่งไปเซิร์ฟเวอร์ ส่วนผลของเสียง AI เป็นข้อมูลที่เตรียมไว้แยกกัน การฟังตัวอย่างและเรียนบทเรียนไม่ต้องดาวน์โหลดโมเดล

การวิเคราะห์ใช้หน่วยความจำมากกว่าขนาดไฟล์โมเดลและอาจช้าในโทรศัพท์หรือเครื่องเก่า ลองเริ่มจากคำหรือประโยคสั้น ๆ หากอุปกรณ์ไม่รองรับยังฟังและอัดเสียงได้ หรือใช้ [บริการวิเคราะห์ในเครื่อง](speech-training/README.md#local-service)
