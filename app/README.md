# English Garden Lab

แอปฝึกอังกฤษสำหรับผู้ใหญ่ไทย ผ่านสวน คำศัพท์ และบทสนทนาสั้น ๆ กับมะลิ เปิด [แอปเรียน](index.html) หรือ [หน้าฝึกฟังและพูด](../speech-training/listen.html) ได้โดยไม่ต้องมีบัญชีหรือ API key

## เริ่มใช้งาน

เดโมที่เปิดผ่าน HTTPS ใช้เรียน บันทึกเสียง และฟังเสียงตัวเองได้ในเบราว์เซอร์ หากดาวน์โหลด repository ให้รันจากโฟลเดอร์หลัก:

```sh
python3 speech-training/build_demo.py
python3 -m http.server 8765 --bind 127.0.0.1 --directory dist
```

เปิด <http://127.0.0.1:8765/app/index.html> หรือ <http://127.0.0.1:8765/speech-training/listen.html> แล้วหยุด server ด้วย **Ctrl+C** ขั้น build จัดไฟล์เดโมและเสียงตัวอย่างลง `dist/` โดยไม่ดาวน์โหลดโมเดล ส่วนการดับเบิลคลิกซอร์ส `app/index.html` ใช้อ่านและเรียนได้ แต่ควรเปิดเดโมผ่าน HTTPS หรือ localhost เมื่อต้องใช้เสียงตัวอย่างและไมโครโฟน

## เรียนและฝึกเสียง

มี 3 บท: **สวนของฉัน**, **ขอให้ AI ช่วย**, และ **คุยกับมะลิ** พร้อมสวน 2D ที่กดสำรวจ คลังคำศัพท์ และการทบทวน บทสนทนาเป็นสคริปต์ที่เตรียมไว้

เครื่องมือฝึกออกเสียงแบ่งเป็น 3 ขั้น:

1. **อ่านและฟัง:** อ่านประโยคพร้อมคำแปลไทย แตะคำเพื่อดูความหมาย แยกหน่วยเสียง และฟังคำตัวอย่าง เปิด IPA ฉบับเต็มได้ในรายละเอียด
2. **ลองพูด:** เลือกฝึกทั้งประโยคหรือ “ฝึกคำนี้” กดบันทึก แล้วหยุดและรอเตรียมเสียง กด **ฟังเสียงของฉัน**, พักเสียง หรือฟังใหม่ตั้งแต่ต้นได้ รับเสียงไม่เกิน 15 วินาที / 10 MB
3. **ดูผล:** เดโมออนไลน์แสดงได้เฉพาะ **ผลวิเคราะห์เสียงตัวอย่างที่เตรียมไว้** ของเสียง AI ส่วนการวิเคราะห์ไฟล์ใหม่ของผู้เรียนต้องเปิดรุ่นในเครื่อง

หน้า A/B ให้ฟังเสียงก่อนและหลังการทดลองปรับโมเดล โดยสลับชื่อเป็น A/B จนกดเฉลย ผลวิเคราะห์ที่เตรียมไว้ผูกกับไฟล์เสียงตัวอย่างจริง ไม่ถูกนำไปใช้เป็นผลของเสียงที่คุณบันทึก

เปอร์เซ็นต์หมายถึง **จำนวนหน่วยเสียงที่จับคู่กับอ้างอิง ÷ (หน่วยเสียงอ้างอิง + เสียงที่ตรวจพบเพิ่ม) × 100** แสดงรายคำและทั้งประโยค พร้อมจำนวนที่จับคู่ได้ ใช้สีม่วง → น้ำเงิน → คราม → ฟ้า → เขียว → เหลือง → แสด → แดง ตามช่วง 95 / 90 / 80 / 70 / 60 / 50 / 40% และใช้ “—” เมื่อข้อมูลไม่พอ ค่านี้ไม่ใช่ความมั่นใจของโมเดลหรือคะแนนความสามารถภาษาอังกฤษ

## เดโมออนไลน์กับรุ่นในเครื่อง

**เดโมออนไลน์:** คำอ่าน US และเสียง AI ตัวอย่างอยู่ใน repository แล้ว บันทึกและเตรียม WAV เพื่อฟังซ้ำภายในเบราว์เซอร์ ไม่มีการส่งเสียงของผู้ใช้ไปวิเคราะห์ และไม่ติดต่อบริการ localhost ของผู้เข้าชม หากเบราว์เซอร์เตรียมเสียงไม่ได้ ให้เลือกไฟล์ WAV หรือใช้รุ่นในเครื่อง คำอ่าน UK และข้อความนอกชุดที่เตรียมไว้ต้องใช้รุ่นในเครื่องเช่นกัน

**รุ่นในเครื่อง:** ติดตั้งตาม [คู่มือบริการเสียง](../speech-training/README.md#local-service) แล้วเปิดแอปผ่าน `http://127.0.0.1:8766/app/index.html` จึงใช้วิเคราะห์เสียงใหม่ได้ หากเบราว์เซอร์ถอดไฟล์บันทึกไม่ได้ บริการในเครื่องจะช่วยเตรียม WAV ก่อนฟัง การวิเคราะห์หน่วยเสียงเริ่มเมื่อกดดูผล ไฟล์ชั่วคราวถูกลบหลังอ่านเสียง

หน้าเว็บไม่เปิดไมค์หรือส่งไฟล์เองเมื่อเปิดหน้า การฝึกคำแยกจากผลประโยค และปุ่มกลับไปฝึกทั้งประโยคเรียกผลเดิมคืนได้

## ความคืบหน้า

บทเรียนบันทึกความคืบหน้าใน `localStorage` ของเบราว์เซอร์ ใช้หน้าผลการเรียนเพื่อส่งออก/นำเข้า JSON สำรองข้อมูล การเปลี่ยนเบราว์เซอร์ host หรือพอร์ตเป็นคนละพื้นที่บันทึก หากบันทึกไม่ได้ แอปจะแจ้งว่าใช้หน่วยความจำชั่วคราว ผล phonetics ไม่รวมอยู่ในคะแนนหรือไฟล์ความคืบหน้าบทเรียน
