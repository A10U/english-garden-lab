# English Garden Lab

แอปฝึกอังกฤษสำหรับผู้ใหญ่ไทย ผ่านสวน คำศัพท์ และบทสนทนาสั้น ๆ กับมะลิ เปิด [แอปเรียน](index.html) หรือ [หน้าฝึกฟังและพูด](../speech-training/listen.html) ได้โดยไม่ต้องมีบัญชีหรือ API key

## เริ่มใช้งาน

เดโมที่เปิดผ่าน HTTPS ใช้เรียน บันทึกเสียง และฟังเสียงตัวเองได้ในเบราว์เซอร์ หากดาวน์โหลด repository ให้รันจากโฟลเดอร์หลัก:

```sh
python3 speech-training/build_demo.py
python3 -m http.server 8765 --bind 127.0.0.1 --directory dist
```

เปิด <http://127.0.0.1:8765/app/index.html> หรือ <http://127.0.0.1:8765/speech-training/listen.html> แล้วหยุด server ด้วย **Ctrl+C** ขั้น build จัดไฟล์เดโมและเสียงตัวอย่างลง `dist/` โดยไม่ดาวน์โหลดโมเดล ส่วนการดับเบิลคลิกซอร์ส `app/index.html` ใช้อ่านและเรียนได้ แต่ควรเปิดเดโมผ่าน HTTPS หรือ localhost เมื่อต้องใช้เสียงตัวอย่างและไมโครโฟน

## เรียนและฝึกเสียง

มี 3 บท: **สวนของฉัน**, **ขอให้ AI ช่วย**, และ **คุยกับมะลิ** พร้อมสวน 2D ที่กดสำรวจ คลังคำศัพท์ และการทบทวน บทสนทนาเป็นสคริปต์ที่เตรียมไว้

เครื่องมือฝึกออกเสียงแบ่งเป็น 3 ขั้น:

1. **อ่านและฟัง:** อ่านประโยคพร้อมคำแปลไทย แตะคำเพื่อดูความหมาย กลุ่มตัวสะกดที่สัมพันธ์กับเสียง และฟังคำตัวอย่าง เปิด IPA ฉบับเต็มได้ในรายละเอียด
2. **ลองพูด:** เลือกฝึกทั้งประโยค คำ หรือหน่วยเสียงที่เลือก กดบันทึก แล้วหยุดและรอเตรียมเสียง กด **ฟังเสียงของฉัน**, พักเสียง หรือฟังใหม่ตั้งแต่ต้นได้ รับเสียงไม่เกิน 15 วินาที / 10 MB
3. **ดูผล:** กด **ดูผลเสียงของฉัน** เพื่อให้โมเดลอ่านหน่วยเสียงจากเสียงที่บันทึกจริงในเบราว์เซอร์ ครั้งแรกจะดาวน์โหลดโมเดลประมาณ **318 MB** และชุดประมวลผลประมาณ **12 MB** ส่วนเสียง AI ใช้ **ผลวิเคราะห์เสียงตัวอย่างที่เตรียมไว้** ซึ่งแยกจากผลของคุณ

การอัดเสียงใช้ AudioWorklet เก็บเสียงไมค์เป็น PCM แล้วสร้าง WAV โดยตรง เพื่อเลี่ยงไฟล์เสียงขาดช่วงจากตัวเข้ารหัสของเบราว์เซอร์ รวมถึง Chrome บน iPhone หากใช้วิธีนี้ไม่ได้จะใช้ MediaRecorder แทน แอปตรวจความยาวเสียงเทียบกับเวลาที่อัดจริงและแจ้งให้ลองใหม่เมื่อเสียงขาดหาย โดยยังรับคำสั้นได้ตามปกติ

หน้า A/B ให้ฟังเสียงก่อนและหลังการทดลองปรับโมเดล โดยสลับชื่อเป็น A/B จนกดเฉลย ผลวิเคราะห์ที่เตรียมไว้ผูกกับไฟล์เสียงตัวอย่างจริง ไม่ถูกนำไปใช้เป็นผลของเสียงที่คุณบันทึก

ตัวอย่าง **leaf** แบ่งเป็น **l / ea / f** ที่สัมพันธ์กับเสียง **/l/ /iː/ /f/** กลุ่ม `ea` มีสองตัวอักษรแต่ใช้แทนเสียงเดียว ส่วน **L–E–A–F** คือชื่ออักษรสำหรับสะกดคำ ตัวช่วยแสดงกลุ่มอักษร เช่น `ee`, `th` และอักษรไม่ออกเสียงในคำที่มีข้อมูล เช่น `e` ท้าย **make** เมื่อยังไม่มีข้อมูลหรือเสียงอ้างอิงไม่ตรง ตัวช่วยจะแจ้งว่าแบ่งกลุ่มไม่ได้ การสะกดภาษาอังกฤษไม่ได้มีความสัมพันธ์หนึ่งตัวอักษรต่อหนึ่งเสียงเสมอ

เสียงคำตัวอย่างเป็น **คำเต็มที่สังเคราะห์แยกไว้** ไม่ตัดคำจากประโยค ปุ่มตัวอย่างของหน่วยเสียงยังเล่นคำเต็มพร้อมชี้ว่ากำลังฝึกส่วนใด ใช้ขั้นตอนวางปากช่วยฝึกเสียงเดี่ยว โดยไม่อ้างว่าไฟล์คำเต็มเป็นเสียงหน่วยเสียงโดด ๆ หากไม่มีไฟล์คำนั้น แอปใช้เสียงอ่านอังกฤษที่ติดตั้งในเครื่องเมื่อผู้ใช้กดฟังและแสดงป้ายแหล่งเสียง ส่วนการฟังเสียงที่บันทึกหรือเสียงที่ตรวจพบจะเล่นไฟล์เต็ม ไม่หยุดตัดตามขอบเขตที่โมเดลประมาณ

การฝึกคำเดี่ยวใช้คำอ่านอ้างอิงของคำเดี่ยว ส่วนคำสั้นในประโยคอาจมีรูปเสียงเบาต่างกัน เช่น `a` หากเสียงที่เลือกเป็นรูปตามบริบทและไม่ตรงกับคำเดี่ยว แอปให้ฟังประโยคเต็มพร้อมคำอธิบายความต่าง

ส่วนเปรียบเทียบสระมีคำคู่ **A/B** สำหรับฟังความต่างของสระ เลือกฟังปกติหรือฟังช้า แล้วสังเกตลิ้นและริมฝีปากตามคำอธิบาย เสียงทั้งสองด้านมาจากผู้พูดเดียวกันและเป็นคำเต็มที่สังเคราะห์แยกคำ ไม่ใช่เสียงสระที่ตัดออกจากคลิป หากยังไม่มีไฟล์ตัวอย่าง แอปจะแจ้งหรือใช้เสียงอังกฤษในเครื่องพร้อมระบุแหล่งเสียง

เสียงสระเดี่ยวเป็นเสียงมนุษย์ต้นฉบับฉบับเต็มสำหรับเทียบคุณภาพสระตาม IPA และตำแหน่งลิ้น/ริมฝีปาก ดู [เครดิตและสิทธิ์รายไฟล์](assets/vowels/ATTRIBUTION.md) เสียงฐาน /i/, /u/, /ɑ/, /ɔ/ ช่วยอธิบายคุณภาพเสียง /iː/, /uː/, /ɑː/, /ɔː/ แต่ไม่ใช่ตัวอย่างระยะเวลาสระในคำภาษาอังกฤษ ส่วนสระประสมใช้คำเต็มและคำอธิบายการเลื่อนเสียง

วิดีโอสอนจากผู้สร้างมีปุ่มกดเปิดในหน้าและลิงก์ไป YouTube หน้าเว็บยังไม่สร้างเครื่องเล่นจนกดเปิด และไม่เริ่มเล่นเอง การเปิดวิดีโอจะเชื่อมต่อบริการ YouTube แยกจากการวิเคราะห์เสียงที่ทำในเบราว์เซอร์

เมื่อเลือกหน่วยเสียง ตัวช่วยพื้นฐานอธิบาย **ตำแหน่งที่เกิดเสียง**, **วิธีกั้นหรือปล่อยลม**, **การสั่นของเส้นเสียง**, ทางลมผ่านปากหรือจมูก และการวางลิ้นกับรูปริมฝีปาก ลองตามขั้นตอนจัดปาก → เปล่งเสียง → เชื่อมกลับเป็นคำ โดยใช้คำอธิบายไทยและแผนภาพตัดข้างช่วยเรียน แผนภาพเป็นแบบจำลองโดยประมาณและไม่ได้แสดงการเคลื่อนไหวจริงของผู้ใช้ เนื้อหานี้สอนกลไกการเกิดเสียงตามสัทศาสตร์ ไม่ใช่ประวัติหรือรากศัพท์ของคำ

ระบบรับเฉพาะเสียงและไม่ได้ใช้กล้องเพื่อตรวจตำแหน่งลิ้นหรือริมฝีปาก ผลจาก acoustic model จึงใช้ฟังเทียบประกอบคำแนะนำ ไม่ได้ยืนยันว่าจัดปากถูกต้องทุกส่วน

ภาพตัดข้าง 20 ภาพเป็นไฟล์ต้นฉบับไม่ดัดแปลง พร้อมผู้สร้างและลิงก์แหล่งภาพ/ใบอนุญาตใต้ภาพ ดู [เครดิตภาพทั้งหมด](assets/articulation/ATTRIBUTION.md) สำหรับสิทธิ์รายไฟล์ ภาพสระ /i/ ช่วยอธิบายตำแหน่งลิ้นสำหรับ /iː/ แต่ไม่แสดงความยาวเสียง ส่วนภาพ /l/ เปรียบเทียบสองตำแหน่ง หากไม่มีภาพของเสียงนั้นหรือโหลดไม่ได้ แอปใช้แผนภาพย่อพร้อมคำอธิบายข้อจำกัด

การฝึกหน่วยเสียงเดี่ยวเป็นโหมดทดลอง โมเดลอ่านเสียงจริงและอาจตรวจเสียงสั้นหรือเสียงหยุดได้ไม่ครบ ใช้ฟังเทียบและลองพูดซ้ำ ผลเป็นค่าประมาณ ไม่ใช่คะแนนการออกเสียงที่สอบเทียบแล้ว และแยกจากผลคำหรือทั้งประโยค

เปอร์เซ็นต์หมายถึง **จำนวนหน่วยเสียงที่จับคู่กับอ้างอิง ÷ (หน่วยเสียงอ้างอิง + เสียงที่ตรวจพบเพิ่ม) × 100** แสดงรายหน่วยเสียง กลุ่มตัวสะกด คำ และทั้งประโยค พร้อมจำนวนที่จับคู่ได้ ใช้สีม่วง → น้ำเงิน → คราม → ฟ้า → เขียว → เหลือง → ส้ม → แดง ตามช่วง 95 / 90 / 80 / 70 / 60 / 50 / 40% และใช้ “—” เมื่อข้อมูลไม่พอ ค่านี้ไม่ใช่ความมั่นใจของโมเดลหรือคะแนนความสามารถภาษาอังกฤษ

เมื่อโมเดลตรวจหน่วยเสียงได้ไม่มั่นคง แอปแสดง **“ยังประเมินการออกเสียงไม่ได้”** และ “—” ทั้งระดับคำและรายเสียง โดยยังฟังเสียงตัวเองและดูผลคาดเดาในรายละเอียดได้ ไม่แนะนำให้แก้ตำแหน่งปากจากผลที่ไม่มั่นคง การตรวจนี้ใช้ค่าเฉลี่ย posterior ของเฟรม CTC ที่เลือกหน่วยเสียง (ไม่รวม blank) ต่ำกว่า 0.65 เป็นเกณฑ์ทดลอง ไม่ใช่ความน่าจะเป็นว่าผู้เรียนพูดถูก และยังต้องสอบเทียบกับข้อมูลจริงเพิ่มเติม ผลจับคู่ดิบยังอยู่ครบ ส่วนผลที่ผ่านเกณฑ์ยังแสดง 0% ได้เมื่อไม่พบหน่วยเสียงที่ตรงกัน

ผลรายกลุ่มมาจากหน่วยเสียงที่โมเดล CTC ตรวจพบจริงแล้วนำมาจับคู่ หน่วยเสียงเดียวจึงมักเป็น **0% หรือ 100%** ส่วนกลุ่มหลายเสียงรวมจำนวนที่จับคู่ได้ ระบบแนะนำส่วนที่จับคู่ได้น้อยให้เริ่มฝึกก่อน แตะส่วนนั้นเพื่อดูวิธีวางปาก ฟังคำตัวอย่างเต็ม และลองบันทึกใหม่ อักษรเงียบหรือส่วนที่ยังเทียบไม่ได้ไม่ถูกสร้างเปอร์เซ็นต์ขึ้นมา การฟังยังเล่นคำเต็มหรือไฟล์เสียงของคุณเต็มคลิป

## เดโมออนไลน์กับรุ่นในเครื่อง

**เดโมออนไลน์:** คำอ่าน US และเสียง AI ตัวอย่างอยู่ใน repository แล้ว บันทึก เตรียม WAV และวิเคราะห์เสียงของคุณภายในเบราว์เซอร์ ไม่ส่งเสียงไปเซิร์ฟเวอร์และไม่ติดต่อ localhost ของผู้เข้าชม เมื่อกดวิเคราะห์ครั้งแรกจึงดาวน์โหลดโมเดลจาก Hugging Face การดาวน์โหลดนี้เป็นการรับไฟล์โมเดล ไม่ใช่การส่งเสียงไปคลาวด์ คำอ่าน UK และข้อความนอกชุดที่เตรียมไว้ต้องใช้รุ่นในเครื่อง

โมเดลทำงานผ่าน WebAssembly ใน worker แยกจากหน้าจอ ใช้หน่วยความจำมากกว่าขนาดไฟล์ 318 MB และอาจช้าบนอุปกรณ์บางรุ่น เริ่มจากเสียงสั้น ๆ ได้ หากโหลดโมเดลไม่สำเร็จยังเรียน ฟังตัวอย่าง และฟังเสียงตัวเองได้ หากเบราว์เซอร์เตรียมเสียงไม่ได้ ให้เลือกไฟล์ WAV หรือใช้รุ่นในเครื่อง

**รุ่นในเครื่อง:** ติดตั้งตาม [คู่มือบริการเสียง](../speech-training/README.md#local-service) แล้วเปิดแอปผ่าน `http://127.0.0.1:8766/app/index.html` เพื่อใช้บริการ Python ในเครื่องแทนโมเดลในเบราว์เซอร์ หากเบราว์เซอร์ถอดไฟล์บันทึกไม่ได้ บริการนี้ช่วยเตรียม WAV ก่อนฟัง การวิเคราะห์หน่วยเสียงเริ่มเมื่อกดดูผล ไฟล์ชั่วคราวถูกลบหลังอ่านเสียง

หน้าเว็บไม่เปิดไมค์หรือส่งไฟล์เองเมื่อเปิดหน้า การฝึกคำแยกจากผลประโยค และปุ่มกลับไปฝึกทั้งประโยคเรียกผลเดิมคืนได้

## ความคืบหน้า

บทเรียนบันทึกความคืบหน้าใน `localStorage` ของเบราว์เซอร์ ใช้หน้าผลการเรียนเพื่อส่งออก/นำเข้า JSON สำรองข้อมูล การเปลี่ยนเบราว์เซอร์ host หรือพอร์ตเป็นคนละพื้นที่บันทึก หากบันทึกไม่ได้ แอปจะแจ้งว่าใช้หน่วยความจำชั่วคราว ผล phonetics ไม่รวมอยู่ในคะแนนหรือไฟล์ความคืบหน้าบทเรียน
