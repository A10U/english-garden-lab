# เนื้อหาต้นแบบ English Garden Lab

ฉบับ 1.0.0 • 24 ตุลาคม 2569 • ประโยคและกิจกรรมแต่งใหม่จากแนวคิดหลักสูตรใน SDLC ไม่คัดแบบฝึกหัด หนังสือ เสียง หรือบทถอดวิดีโอใน Resource

ไฟล์ `content.js` กำหนด `globalThis.EGL_CONTENT` โดยไม่มี module import, network request, storage, ไมค์ หรือ logic ให้คะแนน ส่วน engine และหน้าจอเป็นผู้เลือกแสดงกิจกรรมและบันทึกผล

## สามบทที่เรียนจบเป็นวงจรได้

- **G01 สวนของฉัน:** leaf / plant / green; ฟังสิ่งที่กำลังพูดถึง อ่านสีของใบไม้ เขียน “This is a leaf.” ลองพูด และเรียกคำ leaf จากความหมายไทยก่อนเปิดคำใบ้
- **A01 ขอให้ AI ช่วย:** help / write / ask; ฟังคำขอ อ่าน “Write one sentence about a leaf.” เขียนคำขอสุภาพ ลองพูด และเรียกคำ help จากความจำ จากนั้นเลือกคำขอในบทสนทนาจำลอง
- **C01 คุยกับมะลิ:** like / plants / again; ฟังคำขอพูดซ้ำ อ่านความชอบ เขียนประโยคตามโจทย์ ลองพูดขอฟังอีกครั้ง และเรียกคำ again บทสนทนาให้เลือกชอบ/ไม่ชอบ/ขอฟังซ้ำได้ทั้งหมด ไม่มีความชอบส่วนตัวที่ผิด

แต่ละบทเสนอประมาณ **10 นาที** เป็นค่าตั้งต้นทดลอง ไม่ใช่เวลาที่พิสูจน์ว่าเหมาะกับทุกคน มีคำศัพท์เป้าหมาย 9 รูปคำ (plant/plants เป็นคนละรูปของคำเดียวกัน) และ glossary ช่วยอ่านรวม **20 รายการ** รวมวลีสำเร็จรูป ตัวอย่างประโยคอาจมีคำหน้าที่ประกอบประโยคที่ไม่ใช่ศัพท์เป้าหมาย ไม่ต้องท่องทุกคำก่อนเริ่ม ใช้ภาษาไทยและวลีทั้งก้อนช่วยเข้าใจได้

## สัญญาข้อมูลที่ engine ใช้

ทุกบทมี id/title/eyebrow/description/minutes/theme/goal/words/intro/listen/read/write/speak/recall/dialogue ตาม contract ที่ตกลง `listen.audio` เป็นข้อความสำหรับอ่านเสียง ไม่ใช่ URL; ตัวเลือกเป็น `{id,text}` และคำตอบอ้างด้วย `correctId` รหัสไม่ซ้ำในแต่ละชุด ตัวเลือกถูกอยู่ต่างตำแหน่ง ไม่บังคับให้ข้อแรกถูกเสมอ

`write.accepted` คือชุด **ประโยคเต็มที่กำหนดไว้** ไม่ใช่ตัวอย่างให้ LLM ตรวจความหมาย กรณี A01 ยอมรับทั้ง “Help me, please.”, แบบไม่ใส่ comma และ “Please help me.” ให้ engine normalize ตัวพิมพ์ ช่องว่าง และ punctuation ตามกติกาที่แสดง แต่ไม่ใช้ substring matching หากตอบเป็นประโยคภาษาอังกฤษที่ใช้ได้แต่ยังนอกชุดนี้ ควรบอกว่า “ยังไม่ตรงรูปแบบของโจทย์นี้” แทนการกล่าวว่าเป็นภาษาอังกฤษผิดทุกกรณี ไม่มีบริการ AI ให้คะแนนการเขียนอิสระในไฟล์นี้

`recall.prompt` ใช้ความหมายไทย ไม่แสดงคำอังกฤษเป้าหมาย ส่วน `hint` เปิดเผยคำบางส่วน/คำตอบได้เมื่อกดขอความช่วยเหลือ ให้เก็บว่ากดคำใบ้ก่อนตอบหรือไม่ การตอบทันทีหลังเรียนเป็นการฝึกเรียกคำ ยังไม่ใช่หลักฐานจำได้หลังเว้นหลายวัน เมื่อใช้ในคิวทบทวนให้ engine เก็บเวลาห่างจริงและแยก assisted/independent

`dialogue.lines` เป็นบทที่เตรียมไว้ ผู้พูดใช้ชื่อ Mali/You/AI ตาม contract `choices.reply` เป็นข้อความตอบสคริปต์ ไม่ได้สร้างสด ตัวแปร `helpful` บอกว่าตัวเลือกช่วยทำภารกิจเฉพาะนี้หรือไม่ ไม่ใช่คะแนนคุณค่าคนหรือความสัมพันธ์ มะลิเป็นตัวละครนักพฤกษศาสตร์ผู้ใหญ่สมมติ และ C01 ทุกตัวเลือกมี helpful=true เพราะการตอบความชอบต่างกันและขอฟังซ้ำเหมาะสมได้ทั้งหมด

## เก็บหลักฐานสี่ทักษะโดยไม่ปนกัน

**LO-01 ฟัง:** ก่อนตอบ listening ให้ engine ซ่อน transcript/คำแปล/intro ที่เปิดคำตอบ และบันทึกเมื่อกดเปิดคำช่วย หากเสียงใช้ไม่ได้ ให้มีทางทำต่อในโหมดอ่านช่วยพร้อมระบุว่าไม่ใช่หลักฐานฟังล้วน

**LO-02 อ่าน:** แสดง `read.text` ได้โดยตรง เพราะโจทย์ถามข้อมูลที่อยู่ในข้อความไทย/อังกฤษ มีคำช่วยสำหรับผู้เริ่มต้นและบันทึกความช่วยเหลือแยกได้

**LO-03 พูด:** `speak` ให้ลองพูดเองแล้วสะท้อนตนเอง ข้ามได้ ส่วน phonetics เป็นตัวช่วยเลือกใช้: ดู IPA อัด/อัปโหลดเสียงเพื่อเทียบหน่วยเสียงกับคำอ่านอ้างอิงผ่านบริการในเครื่อง ผลนี้เป็นสถานะชั่วคราวของ widget ไม่ถูกแปลงเป็นคะแนนหรือเขียนทับ `speaking` เดิม การพิมพ์แทน/กดบทสนทนาไม่ถือว่าผ่านทักษะพูด การสะท้อนตนเองเป็นสิ่งที่ผู้เรียนรายงาน ไม่ใช่ผลประเมินโดยผู้ฟัง ตัวช่วย IPA ไม่แสดงในโจทย์ฟังก่อนเปิดคำช่วย

**LO-04 เขียน:** ตรวจรูปประโยคตามชุดที่กำหนด บันทึกว่าผู้เรียนเปิด scaffold/hint หรือไม่ C01 “I like plants.” เป็นข้อความตามโจทย์ ไม่ตีความเป็นความชอบจริงของผู้เรียน ความชอบจริงเลือกได้ในบทสนทนา

**LO-05 เรียกความจำ:** เนื้อหาข้อทบทวนพร้อมใช้ แต่ผลจำหลังเว้นช่วงต้องเกิดจากการกลับมาทำในภายหลังและเก็บช่วงห่างจริง ไม่เปลี่ยนการทำครั้งเดียวเป็นผล retention

## ข้อมูลต้นไม้และขอบเขต

`plantSample` เป็นตัวเลขจำลอง: อุณหภูมิ 28 °C, แสง 860 lux, ความชื้นดิน 42% เพื่อฝึกอ่าน UI ต้องแสดงหน่วยและป้ายจำลองเสมอ ไม่อ้างว่าเป็นค่าปัจจุบันจาก test_plant ไม่ใช้ตัวเลขนี้สรุปการรดน้ำหรือสุขภาพพืช และไม่มีคำสั่งปั๊ม/ไฟ

เนื้อหามีโครงพร้อมทดลอง แต่ยังไม่ได้ทดสอบผู้เรียนจริง ตรวจคุณภาพเสียงที่เครื่องเป้าหมาย หรือรับรองระดับ CEFR ผู้เรียนควรลองใช้งานและประเมินความเข้าใจกับผู้สอนเพิ่มเติม
