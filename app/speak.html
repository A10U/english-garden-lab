กำลังตรวจ Cloud…

กำลังตรวจว่าบริการสนทนาพร้อมใช้งานหรือไม่

บริการ Cloud ต้องเข้าสู่ระบบก่อน เข้าสู่ระบบเพื่อใช้ Cloud แล้วใส่ key ส่วนตัวอีกครั้งหลังกลับมาหน้านี้

ใช้ OpenAI API key ของคุณ

key อยู่ในหน่วยความจำของแท็บนี้จนกดล้างหรือออกจากหน้า การตรวจบริการไม่ส่ง key เมื่อกดส่งข้อความหรือถอดเสียงผ่าน Cloud จึงส่ง key ผ่านเซิร์ฟเวอร์ของเว็บไป OpenAI อาจมีค่าใช้บริการในบัญชีของคุณ

ยังไม่ได้ตั้ง key ส่วนตัว

หน้านี้ยังใช้ Cloud ไม่ได้ เปิด Speak ที่รองรับ Cloud แล้วใส่ key บนหน้านั้น
